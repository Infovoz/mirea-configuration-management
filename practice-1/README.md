### Задача 1
**Условие:** Вывести отсортированный список имен пользователей системы.  
**Решение:**
```bash
grep -o '^[^:]*' /etc/passwd | sort
```

---

### Задача 2
**Условие:** Вывести 5 наибольших номеров портов протоколов из `/etc/protocols`.  
**Решение:**
```bash
grep -v '^#' /etc/protocols | awk '{print $2, $1}' | sort -rn | head -n 5
```

### Задача 3
**Условие:** Написать скрипт `banner`, который выводит переданную строку в рамке.  
**Решение:**
```bash
#!/bin/bash
text="$1"
len=${#text}
dash=$(printf "%-${len}s" "" | tr ' ' '-')

echo "+-${dash}-+"
echo "| ${text} |"
echo "+-${dash}-+"
```

### Задача 4
**Условие:** Написать программу для вывода всех уникальных идентификаторов языка Си из исходного файла.  
**Решение:**
```bash
grep -oE '\b[a-zA-Z_][a-zA-Z0-9_]*\b' main.c | sort -u | tr '\n' ' '
```

### Задача 5
**Условие:** Написать скрипт `reg`, который делает файл исполняемым и копирует его в `/usr/local/bin`.  
**Решение:**
```bash
#!/bin/bash
if [ -z "$1" ]; then
    echo "Использование: $0 <имя_файла>"
    exit 1
fi

chmod 755 "$1"
sudo cp "$1" /usr/local/bin/
```

### Задача 6
**Условие:** Написать программу для проверки наличия комментария в первой строке файлов `.py`, `.c`, `.js`.  
**Решение:**
```bash
#!/bin/bash
read -r line < "$1"

if [[ "$1" == *.py && "$line" == "#"* ]]; then
    echo "Есть комментарий"
elif [[ ( "$1" == *.c || "$1" == *.js ) && ( "$line" == "//"* || "$line" == "/*"* ) ]]; then
    echo "Есть комментарий"
else
    echo "Нет комментария"
fi
```

### Задача 7
**Условие:** Написать программу для поиска файлов-дубликатов по заданному пути.  
**Решение:**
```bash
#!/bin/bash
TARGET="${1:-.}"
find "$TARGET" -type f -exec md5sum {} + | sort | uniq -w32 -d --all-repeated=separate
```

### Задача 8
**Условие:** Написать программу, которая находит файлы с заданным расширением и упаковывает их в архив `tar`.  
**Решение:**
```bash
#!/bin/bash
EXT="$1"
tar -cf "archive_${EXT}.tar" *."${EXT}"
```

### Задача 9
**Условие:** Написать программу, которая заменяет 4 пробела подряд на символ табуляции.  
**Решение:**
```bash
#!/bin/bash
sed 's/    /\t/g' "$1" > "$2"
```

### Задача 10
**Условие:** Написать программу, выводящую имена всех пустых файлов `.txt` в указанной директории.  
**Решение:**
```bash
#!/bin/bash
DIR="$1"
find "$DIR" -type f -name "*.txt" -empty
```
